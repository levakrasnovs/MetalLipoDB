# MetalLipoDB modeling

This directory contains the modeling workflow of the paper. The scripts use only relative paths and share one module, `features.py`, which defines the model inputs (`COMMON_NUMERIC`, `COMMON_CATEGORICAL`) for all models.

## Setup

The environment is defined in `../environment.yml` (Python 3.12, RDKit 2026.3.6,
Chemprop 2.3.1, LightGBM 4.6.0, SHAP 0.48.0). RDKit versions differ in canonical SMILES
and in `NumHAcceptors`, so the modeling table is regenerated when RDKit changes. Versions
are also printed at the top of each script log.

## Running

Run from this directory.

1. `python prepare_data.py` — modeling table (`data/MetalLipoDB_modeling.csv`), frozen
   SMILES/DOI folds (`data/fold_manifest.csv`) and feature dictionary from the released
   `../data/MetalLipoDB.csv`. An existing `data/fold_manifest.csv` is reused, not rebuilt:
   `GroupKFold` orders groups by canonical SMILES, which can change between RDKit
   versions. `--refold` rebuilds it.
   Scripts evaluate SMILES, DOI, LOMO and LOGO (`common.evaluation_folds`; LOMO/LOGO hold out
   every metal/group with ≥20 rows and drop from training all rows containing it and all
   articles with a held-out row). `--splits` with a subset writes tagged outputs.
   `python baselines.py` — per-metal mean, calibrated Crippen logP of the neutral
   ligands, kNN on count Tanimoto and ridge on the shared descriptors, same folds.
2. `python train_lightgbm.py` — LightGBM, count Morgan fingerprint of the ligand set
   (2048) plus the shared descriptors, on SMILES/DOI/LOMO/LOGO, fold-wise SHAP.
   `--fingerprint dative` takes the fingerprint of the whole dative complex instead
   (outputs tagged `_dative`, not used in the paper).
   `--splits LOMO LOGO --keep-articles` keeps in training the articles of the held-out rows
   (outputs tagged `_LOMO_LOGO_kept`, the column "articles kept" of Table S5).
3. `python train_chemprop.py [--representations DATIVE] [--splits ...] [--fresh]` — Chemprop v2
   from scratch (DATIVE graph by default; DOT/SINGLE optional) with the shared descriptors as
   extra features, on SMILES/DOI/LOMO/LOGO; one fixed head for all splits, early stopping on
   10% of the training rows grouped like the split; resumes from finished folds.
4. `python train_chemeleon.py [--representations DATIVE] [--splits ...]` — frozen CheMeleon
   encoder + regression head on the embedding and the shared descriptors, same folds, head and
   early stopping as Chemprop; embeddings cached by molecules and RDKit version.
5. `TABPFN_TOKEN=... python train_tabpfn.py [--splits ...] [--fresh]` — TabPFN API on the
   512-bit count fingerprint plus the shared descriptors, median as the point prediction
   (fixed a priori), 10%/90% quantiles stored; resumes from finished folds. Needs
   `pip install tabpfn-client`.
   `python compare_models.py` — all models from their saved predictions: SMILES/DOI as mean ± SD
   over folds, LOMO/LOGO over all held-out rows, paired per-fold differences from LightGBM,
   ready table rows for the paper (`results/metrics/model_comparison_rows.tex`).
6. `python analyze_domain.py [--model lightgbm]` — nearest-neighbour similarity of each
   test row to its training fold and the error by similarity (uses saved predictions only).
7. `python analyze_practical.py` — for the DOI split: share of the error shared by an article,
   ordering within articles, anchoring to 1-3 measured complexes, empirical prediction intervals by
   similarity (saved predictions only; needs `analyze_domain.py` output).
8. `python time_split.py` — time-split validation of LightGBM (Sheridan 2013): train up to 2023,
   test 2024–2026, and each year predicted from all earlier articles.
9. `python learning_curve.py` — LightGBM trained on subsets of whole articles (250–all) in every
   SMILES/DOI fold. Figures: `../plots/plot_ml_practical.py`, `../plots/plot_time_learning.py`.
10. `python stat_compare.py` — statistical comparison of the models on the SMILES and DOI folds:
    repeated-measures ANOVA and the Tukey HSD test with the variation between folds removed
    (Ash et al. 2025). Figure: `../plots/plot_model_stats.py`.

Shared code: `features.py` (which features enter the models, feature blocks, ligand
fingerprint), `common.py` (paths, SMILES helpers, metrics, data loading).

## Data and outputs

- `../data/MetalLipoDB.csv` (the released table) is the immutable input.
- `data/MetalLipoDB_modeling.csv` is generated by `prepare_data.py`. `data/fold_manifest.csv` holds the frozen folds used in the paper and is reused.
- `results/metrics/` contains fold-level and pooled out-of-fold metrics.
- `results/oof_predictions/` contains one prediction per sample and validation regime.
- `results/figures/` (created on run) contains diagnostic figures.

The TabPFN API token is read only from the `TABPFN_TOKEN` environment variable.
